## 术语速查
| 词 | 意思 |
|---|---|
| **三件套** | 每个符号返回：`向量`（相似度）+ `注释`（`@domain` 显式键）+ `注释文本`（docstring / 可读 note）；另加 `向量近邻`（最近的前 N 个符号） |
| **归因双轨（§12）** | 显式轨（`@domain` 人工键）⇄ 隐式轨（向量相似度软归属）。真实项目**常无 `@domain`，这是设计前提不是缺陷** → 隐式轨自动入域。`domain 永不为空`：实现用目录树 scope〔Q5〕作稳定归属 + 向量软分布并列，§12.6 平等裁决（explicit/implicit/structural/both_agree/conflict/uncertain），§12.7 随 catalog 快照存留 |
| **三通道并列（§13.4）** | 检索返回 `annotation_hits`（注释/域精确）+ `annotation_text_hits`（docstring 词项，**独立并行主线**）+ `vector_hits`（语义 top-k），互不为主、不预融合、交 Agent 裁决。⚠ 别把"文本注释"只当向量原料 |
| **两方向并行** | 文本生成方向（TypeDoc / Storybook / Ladle）⇄ 向量智能方向，**地位平等、互不为主** |
| **Domain 框架** | = 文本方向的可读产出 + 向量方向的归因/检索，并列服务于同一能力域 |
| **catalog 快照** | 提取后落盘的元数据（符号→域 + 来源 + 置信度），渲染读快照、与向量快照同源 |
| **四种「索引」** | `llms.txt`=结构/位置/token成本；向量索引=语义坐标；catalog=域归属；全文倒排=词项。**都是派生指针，不是原始信息**（原始=源码/docstring/`@domain`/注释文本） |
| **三态 T0/T1/T2** | 零人（默认）/ 一人+N Agent / 有人类团队；共用同一 AI 核心 |
| **CI / git hook** | CI=持续集成，远端公共机自动跑「构建→校验→发布」（字母 **I**，非 L）；git hook=commit/push 瞬间触发的本地脚本 |
| **active / v_next** | `active`=对外唯一真相；新版本先在 `v_next` 构建、校验过才原子切换 |
| **fail-closed / unresolved** | 低置信且无人可升级时：不裁决、保留旧 `active`、该项标 `unresolved` 冻结、两侧材料原样并列给下游 Agent |
| **永久冻结**（选项 U1） | `unresolved` 项**不按时间重试**，一直冻结到**外部条件变化**（模型升级 / 新证据 / 代码变更 / 人层开启）才唤醒重裁。事件驱动 → 省算力、零抖动；风险：可能永远沉睡，需「滞留时长」KPI 兜底 |
| **TTL**（选项 U2） | **Time To Live**（存活时长），网络/缓存术语，到期失效重新验证。此处指给冻结项设复查周期 t，每到期**自动重裁一次**。时间驱动 → 保证不遗漏；风险：代码没动也反复跑 jury（空转），需退避/重试上限/内容哈希门 |
| **U3 混合（✅ 已定）** | 事件驱动为主 + 长 TTL 兜底巡检；TTL 到期先验内容哈希/模型版本/宪法版本/审核群版本，全没变只累加滞留计数、不重裁 |
| **宪法两层 / jury / dissent** | 不可变核心 + 可修订层；陪审团（≥2 **异构**模型）；**异议强制可见** |
| **结构性不自审** | `提议者 ≠ 审核者`。宪法核心不靠"AI 碰不到的外部硬约束"守护，而靠「多个异构审核 AI + 严格提示词 + 身份分离」——全 AI 闭环、无外部例外 |

## 当前主路线 = C（零人基线）+ D（可选人层），叠加而非二选一
- **C = 零人全自主 + 结构性不自审 + fail-closed**：① 宪法两层（核心由异构审核群守护）；② 裁决层（jury + judge 出裁决/置信度/dissent）；③ fail-closed 四步兜底；④ 非 Agent 的外部健康探针；⑤ 人层可选默认关；⑥ 只承诺「有界可测可审计」，不承诺永不犯错。
- **D = 三态可切换**：T0/T1/T2 共用同一 AI 核心，人只是可插拔外挂层、`config.yaml` 默认关；绝不出现「某功能只有有人在才能跑」。
- **三层防御各治一个坑**：AI 悄悄放宽自己的规则 → 结构性不自审；没人可升级 → fail-closed；系统全停没人发现 → 外部探针。

## 递归收口（已定案）
用户拍板「就这样吧，**不采用 R1**」→ 采用 **R2 密码抽签 + R3 延迟/冷静期/阈值分级 + R4 联席共识**，**R5** 作诚实边界；**R1 信任根、R6 人层终止均排除**。
不引入任何非 AI 外部信任根，保持「全部 AI、零人」定调纯粹。
两个诚实边界：① 随机 beacon 由多模型门限共同产出（不用外部硬锚）；② `agreement is not truth`，fail-closed 不可省。

## 主线六 · ✅ 已闭合（§13.6）
> 核心发现：世界所有文档质量体系**末端都默认有人工审查兜底真值**，零人定调抽掉了这一环 → 主线六真正解的是「零人时谁做真值审查」。
- **Q-A = B+C+A 三层叠加**：B 声明级溯源（原子声明 → 只挑 FACTUAL_CLAIM → 源码/docstring 作证据 → NLI 判蕴含/矛盾 + distortion 六型）＋ C 发布态 delta 校验 ＋ A 四层文本门禁（断链/lint/新鲜度/代码-文档联动）。生成侧自检 D（Degeneration of Thought）、留人审 E（零人不能跑）均排除。判不了 → fail-closed，不猜。
- **Q-B 读/写侧分工**：读侧不拦截（陈旧只打标、不降权）／写侧严门禁（新 `v_next` 不合格禁发布、保留旧 `active`）；门禁阈值归宪法可修订层。**"不让旧信息消失" ≠ "让不合格的新版本上岗"**。
- **Q-C = S1 源码唯一论为内核 + S2 分层优先为扩展**：代码事实以源码/docstring/git 为准；**派生 KB 产物（生成页、catalog、AI 摘要）不得反过来当证据**（防"AI 摘要引 AI 摘要"循环引用）；约定/意图类走分层。平级投票 S3 排除。
- **源码与注释矛盾 → 判「冲突并排」，不判「不可核验」**：源码与注释两侧原样交给 Agent、不自动偏向任一方。看似与 S1 打架，实则**真值判定（写侧，S1）** 与 **材料呈现（读侧，全给）** 是两件事；S1 挡的是派生文档，并排的是 docstring/`@domain` 这类**一手原始信息**。证据充分只是互相矛盾（注释腐化），是高价值信号，不该折叠成"判不了"。
> 零人 KPI：citation coverage、claim groundedness、abstention 准确率、Search success rate、Freshness SLA 分档；加权总分只作仪表盘、不代替硬门禁。M1 待定：阈值 / NLI 选型 / 轮换查询集 / 覆盖率口径 → `config.yaml`；拟新增标记 `impl_intent_divergence`（仅标记+并排，不拦截、不自动改注释）。

## 主线七 · ✅ 已闭合（§13.7，用户拍板）
> 世界实践：AGENTS.md / Skills / MCP 是**互补三层栈**（项目级自动注入 / 任务级按需加载 / 工具级 live 连接），经验法则「每 session 都要→AGENTS.md；仅部分任务→Skill；需要 live data→MCP」。MCP 工具定义从第一回合全额计费 → 贴合窄腰原则。
1. **Q-1 接入形态 ✅** → **Skill 与 MCP 共用、按读写分工**：**读 = Skill 读指南（R 通道，progressive disclosure，只讲怎么读 KB、不含写能力）**；**写 = MCP git 式提交（W 通道，非只读签名 + 字段白名单 + 幂等键）**。彻底闭合主线一悬着的「Skill vs MCP」——不是二选一，而是各管一端。AGENTS.md 仍唯一入口 / 与 §14.7 宪法自举同源；MCP 是写通道必需基建，但暴露哪些写工具、工具数上限仍走 config.yaml。
2. **Q-2 只读/回写分通道 ✅** → **C2 双通道硬分离落地为「读 = Skill / 写 = MCP」+ 审计外部化**（R 只读签名 `read-only`；W 只写 catalog 候选层软标注、不碰 `active`；审计日志由非 Agent 探针写 append-only，不做成 Agent 接口）。C1 单通道与全稿分权哲学冲突，排除。
   > 世界实践硬要求：「把权限写进**工具签名**而非提示词」、「Pair every write with a read」、分离 read/write 凭证、模型动作当不可信请求由确定性执行器执行前重新鉴权、Agent 不能写自己的审计日志。**W 通道 = git 式提交通道 = §13.8 Q-3 的机制载体**，两条主线并轨。
> 首次接手（幂等）：读根 AGENTS.md → 读 llms.txt 根路由 → 按需拉分片/三件套/近邻 → 按需加载 **Skill 读指南** → **MCP git 式提交**回写软标注（change_reason + 幂等键）→ 事件/定时/自身触发维护 → CI 校验门 → 原子切 active。子目录可放嵌套 AGENTS.md（就近覆盖）。
> 安全必做（非决策）：审计未自写的 skill/MCP；工具描述按**不可信输入**处理；external-URL skill 默认禁。

## 主线八 · ✅ 已闭合（§13.8，用户拍板）
> 核心问题：零人定调下**谁看报表、谁判达标、怎么证明"新 Agent 真的更快接手"**。与 §1 验收标准 / §13.6.2 零人 KPI / §14.5 外部探针对齐，三层合一才是可落地验收。
> 网查硬印证：DocGenBench（文档效用≠像不像人写，lexical gap<0.12，终极判据=独立LLM凭文档重建代码过单测）/ SWD-Bench（文档驱动开发闭环，最好文档让解题率+20%）/ DocAgent（质量拆 completeness/truthfulness↔依赖图/helpfulness）/ 自主Agent可观测范式（SLI/SLO/error budget+行为金丝雀+混沌演练+探针自证）。
1. **Q-1 验收主体 ✅** → **A1 探针 + A2 异构 jury 分工，排除 A3 自评分**；「多 AI 自举」复用 §14.7 宪法自举基建（核心/审核群/验收共用同一异构多 AI 流水线）。验收结论落 append-only，由探针写、非 Agent 写。
2. **Q-2 度量分两类 ✅** → **B2 双类**；硬门禁（truth/freshness/gate，blocking）由 Q-1 多 AI 担负，仪表盘 informational（coverage/discoverability/helpfulness）由**单一 AI** 产出（非阻塞、仅观察，故单 AI 可接受且省算力）。每指标归属写 config.yaml。
3. **Q-3 闭环验收 ✅** → **git 式版本化验收为骨架 + C2 合成接手基准（发布前）+ C3 行为金丝雀（发布后）**：首次建树=初始提交，后期每次改动=一次提交，**强制 `change_reason`（变更原因）**，且**随时可回滚**（落 §13.5 v_next/active 原子切换 + CAS）；C2 决定能否合入 active，C3 守护上线后有无回归。
   > **零人可观测三铁律**：① 度量自动采集；② 达标自动判；③ 不达标自动 fail-closed/回滚/降级。
   > **git 式验收三要素**：① 每变必提交（含首次建树）；② 每提交必带 change_reason；③ 任一提交可回滚——既是审计线索，又是 fail-closed 安全网。
> M1 待定（全走 config.yaml）：每 SLI 的 SLO 阈值与 error budget、C2 任务集与单测、C3 分流比例与回滚阈值、指标→门禁/仪表盘归类、manifest 的 change_reason 模板；消费者 Agent 异构组合归 §14.9 审核群配置。
